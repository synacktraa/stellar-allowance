# Web implementation plan

**Goal:** a page that proves an allowance works while you watch, and a second page that creates
one. Deployed, linkable, in one night.

**Architecture:** a Next.js app in `web/`. The landing page renders a baked run and can replace
it with a live one streamed from `/api/demo/run`, which drives an async generator whose network
calls are injected. `/create` connects Freighter and deploys through the SDK's
`contract.Client`. Design: `docs/specs/2026-09-08-web-design.md`.

**Tech stack:** Next.js 16.3.4 (app router, TypeScript, no Tailwind), `next/font/google` for
Lora, Inter and IBM Plex Mono, `@stellar-allowance/sdk` by `file:../sdk`,
`@stellar/stellar-sdk` 16.3, `@stellar/freighter-api` 6.0.1, `node --test` for units,
Playwright for the viewport proof.

Phase 1 is the shell. Phase 2 is the demo end to end, which is what the email needs. Phase 3 is
the care signals and the responsive proof. Phase 4 deploys. Phase 5 is the create flow, and it
is last so that running out of time costs the least.

---

## Outcome

Shipped and deployed on 2026-09-08, merged as
[#16](https://github.com/synacktraa/stellar-allowance/pull/16) on 2026-09-09.

Phases 1 to 4 held. Phase 5 did not. `/create` was built as written here and thrown out on
sight, for making a form out of something that wanted a table. `/dashboard` replaced it: one
`getLedgerEntries` over 60 derived addresses, a row per allowance, and a side panel that sends
name, rules and deposit to `write` in a single signature.

All three exclusions at the end of this plan expired. The SDK was published as 0.1.1. Listing,
editing, disabling and withdrawing shipped. And the demo route did take a limit of its own after
all, one run at a time per instance, answering 429 to anything that arrives during one.

---

## Decisions this plan makes

**The runner is a generator, and the route is thin.** `runDemo(deps)` yields one event per step
and knows nothing about HTTP. The route turns events into SSE. The bake script turns them into
JSON. Tests feed the generator fake deps.

**Demo amounts.** Deposit 0.05 USDC, cap 0.025, window 17,280 ledgers, seller price 0.01. Three
seller payments cross the cap on the third, so the window refusal needs no rule edit.

**The stranger is refused at simulation.** The seller's own requirements go to
`scheme.createPaymentPayload` with `payTo` swapped for a random address. Nothing is sent to a
facilitator.

**One run at a time per instance.** A module level flag. A second click while one runs gets 429
and the page says so. Friendbot is the real ceiling and no lock changes that.

**Plain CSS.** One `globals.css` with the tokens from the approved preview. Container queries
for the run and the stats. No utility framework to fight over specificity at 3am.

  ```ts
  // web/lib/demo/run.ts
  import { Keypair } from '@stellar/stellar-sdk';
  import { AllowanceRefused } from '@stellar-allowance/sdk';
  import type { DemoEvent } from './events.js';

  export interface Wants { scheme: string; network: string; amount: string; asset: string;
    payTo: string; maxTimeoutSeconds: number; extra?: Record<string, unknown>; }

  export interface Deps {
    fund(address: string): Promise<void>;
    trustline(owner: Keypair): Promise<void>;
    swap(owner: Keypair): Promise<string>;
    seller(): Promise<{ url: string; wants: Wants }>;
    deploy(owner: Keypair, agent: Keypair, wants: Wants): Promise<{ id: string; index: number }>;
    pay(allowance: { id: string; secret: string }, url: string): Promise<{ hash: string; payer: string }>;
    refuse(allowance: { id: string; secret: string }, wants: Wants): Promise<AllowanceRefused>;
  }

  const usdc = (stroops: string | bigint) => (Number(stroops) / 1e7).toFixed(2);

  export async function* runDemo(deps: Deps): AsyncGenerator<DemoEvent> {
    const owner = Keypair.random();
    const agent = Keypair.random();
    const short = (a: string) => `${a.slice(0, 4)}…${a.slice(-4)}`;

    async function* step<T>(base: Omit<DemoEvent, 'state'>, work: () => Promise<T>,
      after: (r: T) => Partial<DemoEvent>): AsyncGenerator<DemoEvent, T | undefined> {
      yield { ...base, state: 'started' };
      try {
        const r = await work();
        yield { ...base, state: 'done', ...after(r) };
        return r;
      } catch (error) {
        if (error instanceof AllowanceRefused) {
          yield { ...base, state: 'refused', rule: error.rule, sub: refusalCopy(error.rule) };
          return undefined;
        }
        yield { ...base, state: 'failed', sub: String((error as Error).message ?? error) };
        throw error;
      }
    }

    try {
      yield* step({ id: 'fund', party: 'owner', title: 'Fund an owner', sub: 'friendbot' },
        () => deps.fund(owner.publicKey()), () => ({ amount: '10,000.00 XLM' }));
      yield* step({ id: 'trustline', party: 'owner', title: 'Add the USDC trustline' },
        () => deps.trustline(owner), () => ({}));
      yield* step({ id: 'swap', party: 'owner', title: 'Swap 10 XLM for USDC', sub: 'testnet DEX, strict send' },
        () => deps.swap(owner), (bal) => ({ amount: `${Number(bal).toFixed(4)} USDC` }));

      const { url, wants } = await deps.seller();
      const price = usdc(wants.amount);

      const deployed = yield* step({ id: 'deploy', party: 'owner', title: 'Deploy the allowance',
        sub: `allowlist: the seller · cap 0.025 USDC per 24h · the agent's key ${short(agent.publicKey())} holds 0.00` },
        () => deps.deploy(owner, agent, wants), (d) => ({ amount: '0.05 USDC in', hash: d.id }));
      if (!deployed) return;
      const allowance = { id: deployed.id, secret: agent.secret() };

      const one = yield* step({ id: 'pay-1', party: 'agent', title: 'Pay the seller', amount: `${price} USDC` },
        () => deps.pay(allowance, url), (r) => ({ sub: 'settled by OpenZeppelin · the payer is the contract', hash: r.hash }));
      if (!one) return;

      yield { id: 'stranger', party: 'agent', title: 'Told to pay a stranger', amount: `${price} USDC`, state: 'started' };
      const refused = await deps.refuse(allowance, wants);
      yield { id: 'stranger', party: 'agent', title: 'Told to pay a stranger', amount: `${price} USDC`,
        state: 'refused', rule: refused.rule, sub: refusalCopy(refused.rule) };

      const two = yield* step({ id: 'pay-2', party: 'agent', title: 'Pay the seller again', amount: `${price} USDC` },
        () => deps.pay(allowance, url), (r) => ({ sub: '0.02 now in the window', hash: r.hash }));
      if (!two) return;

      yield* step({ id: 'pay-3', party: 'agent', title: 'Pay the seller a third time', amount: `${price} USDC` },
        () => deps.pay(allowance, url), (r) => ({ hash: r.hash }));
    } catch {
      return;
    }
  }

  function refusalCopy(rule: string): string {
    switch (rule) {
      case 'allowlist': return 'not on the allowlist. Refused at simulation; nothing left the contract.';
      case 'window': return '0.03 would exceed the 0.025 cap. Refused; nothing left the contract.';
      default: return `refused by the contract: ${rule}`;
    }
  }
  ```

  ```ts
  // web/lib/allowance/index.ts
  import { Address, Networks, rpc, xdr } from '@stellar/stellar-sdk';
  import { deriveAllowanceAddress } from '@stellar-allowance/sdk';

  export function pickFreeIndex(addresses: string[], taken: Set<string>): number {
    const free = addresses.findIndex((a) => !taken.has(a));
    if (free === -1) throw new Error(`no free index in the first ${addresses.length}`);
    return free;
  }

  export const instanceKey = (id: string) => xdr.LedgerKey.contractData(new xdr.LedgerKeyContractData({
    contract: new Address(id).toScAddress(), key: xdr.ScVal.scvLedgerKeyContractInstance(),
    durability: xdr.ContractDataDurability.persistent() }));

  export async function firstFreeIndex(server: rpc.Server, owner: string, window = 45):
    Promise<{ index: number; address: string }> {
    const addresses = Array.from({ length: window }, (_, i) =>
      deriveAllowanceAddress({ owner, index: i, networkPassphrase: Networks.TESTNET }));
    const { entries } = await server.getLedgerEntries(...addresses.map(instanceKey));
    const taken = new Set(entries.map((e) => Address.fromScAddress(e.key.contractData().contract()).toString()));
    const index = pickFreeIndex(addresses, taken);
    return { index, address: addresses[index] };
  }
  ```

- [ ] **Step 4: The port**

  ```ts
  // web/lib/demo/live.ts
  import { createHash } from 'node:crypto';
  import { Asset, BASE_FEE, Horizon, Keypair, Networks, Operation, TransactionBuilder,
    contract, rpc, xdr } from '@stellar/stellar-sdk';
  import { decodePaymentRequiredHeader, decodePaymentResponseHeader } from '@x402/core/http';
  import { Allowance, AllowanceRefused, generateAllowanceSalt } from '@stellar-allowance/sdk';
  import { firstFreeIndex } from '../allowance/index.js';
  import type { Deps, Wants } from './run.js';

  const NETWORK = Networks.TESTNET;
  const RPC_URL = 'https://soroban-testnet.stellar.org';
  const HORIZON_URL = 'https://horizon-testnet.stellar.org';
  const FRIENDBOT = 'https://friendbot.stellar.org';
  const USDC = new Asset('USDC', 'GBBD47IF6LWK7P7MDEVSCWR7DPUWV3NY3DTQEVFL4NAT4AQH3ZLLFLA5');
  const SELLER_URL = process.env.SELLER_URL ?? 'https://xlm-quote-api.vercel.app/api/quote';
  const WASM_URL = process.env.WASM_URL ??
    'https://github.com/synacktraa/stellar-allowance/releases/download/allowance-contract-v0.2.0/allowance.wasm';
  const DEPOSIT = 500_000n;
  const WINDOW_CAP = 250_000n;
  const WINDOW_LEDGERS = 17_280;

  const server = new rpc.Server(RPC_URL);
  const horizon = new Horizon.Server(HORIZON_URL);

  async function submitClassic(keypair: Keypair, ...ops: xdr.Operation[]) {
    const account = await horizon.loadAccount(keypair.publicKey());
    const tx = ops.reduce((b, op) => b.addOperation(op),
      new TransactionBuilder(account, { fee: BASE_FEE, networkPassphrase: NETWORK })).setTimeout(60).build();
    tx.sign(keypair);
    return horizon.submitTransaction(tx);
  }

  async function pollUntilDone(hash: string) {
    for (let attempt = 0; attempt < 30; attempt += 1) {
      const result = await server.getTransaction(hash);
      if (result.status === 'SUCCESS') return result;
      if (result.status === 'FAILED') throw new Error(`transaction ${hash} failed`);
      await new Promise((r) => setTimeout(r, 1000));
    }
    throw new Error(`transaction ${hash} did not settle`);
  }

  async function ensureWasm(owner: Keypair): Promise<string> {
    const wasm = Buffer.from(await (await fetch(WASM_URL)).arrayBuffer());
    const hash = createHash('sha256').update(wasm).digest('hex');
    const key = xdr.LedgerKey.contractCode(new xdr.LedgerKeyContractCode({ hash: Buffer.from(hash, 'hex') }));
    if ((await server.getLedgerEntries(key)).entries.length) return hash;
    const account = await server.getAccount(owner.publicKey());
    const tx = new TransactionBuilder(account, { fee: BASE_FEE, networkPassphrase: NETWORK })
      .addOperation(Operation.uploadContractWasm({ wasm })).setTimeout(60).build();
    const prepared = await server.prepareTransaction(tx);
    prepared.sign(owner);
    const sent = await server.sendTransaction(prepared);
    if (sent.status === 'ERROR') throw new Error('wasm upload was rejected');
    await pollUntilDone(sent.hash);
    return hash;
  }

  export function liveDeps(): Deps {
    return {
      async fund(address) {
        const r = await fetch(`${FRIENDBOT}?addr=${address}`);
        if (!r.ok) throw new Error(`friendbot returned ${r.status}`);
      },
      async trustline(owner) { await submitClassic(owner, Operation.changeTrust({ asset: USDC })); },
      async swap(owner) {
        await submitClassic(owner, Operation.pathPaymentStrictSend({ sendAsset: Asset.native(), sendAmount: '10',
          destination: owner.publicKey(), destAsset: USDC, destMin: '1', path: [] }));
        const account = await horizon.loadAccount(owner.publicKey());
        const bal = account.balances.find((b) => 'asset_code' in b && b.asset_code === 'USDC');
        return bal?.balance ?? '0';
      },
      async seller() {
        const r = await fetch(SELLER_URL);
        const header = r.headers.get('payment-required');
        if (r.status !== 402 || !header) throw new Error(`the seller answered ${r.status}, not a 402`);
        const [wants] = decodePaymentRequiredHeader(header).accepts;
        return { url: SELLER_URL, wants: wants as Wants };
      },
      async deploy(owner, agent, wants) {
        const { index } = await firstFreeIndex(server, owner.publicKey());
        const wasmHash = await ensureWasm(owner);
        const deployment = await contract.Client.deploy(
          { setup: { owner: owner.publicKey(), agent_key: Buffer.from(agent.rawPublicKey()), name: 'Demo agent',
            spending: { token: wants.asset, initial_deposit: DEPOSIT },
            rules: { window_ledgers: WINDOW_LEDGERS, window_cap: WINDOW_CAP, allowlist: [wants.payTo] } } },
          { wasmHash, salt: generateAllowanceSalt(owner.publicKey(), index), networkPassphrase: NETWORK,
            rpcUrl: RPC_URL, publicKey: owner.publicKey(), signTransaction: new contract.KeypairSigner(owner, NETWORK) });
        const { result } = await deployment.signAndSend();
        return { id: result.options.contractId, index };
      },
      async pay({ id, secret }, url) {
        const response = await new Allowance({ id, secret }).fetch(url);
        const receipt = decodePaymentResponseHeader(response.headers.get('payment-response') ?? '');
        return { hash: receipt.transaction, payer: receipt.payer };
      },
      async refuse({ id, secret }, wants) {
        const allowance = new Allowance({ id, secret });
        try {
          await allowance.scheme.createPaymentPayload(2, { ...wants, payTo: Keypair.random().publicKey() } as never);
        } catch (error) {
          if (error instanceof AllowanceRefused) return error;
          throw error;
        }
        throw new Error('the contract let a stranger through');
      },
    };
  }
  ```

  ```ts
  // web/app/api/demo/run/route.ts
  import { runDemo } from '@/lib/demo/run';
  import { liveDeps } from '@/lib/demo/live';

  export const runtime = 'nodejs';
  export const dynamic = 'force-dynamic';

  let running = false;

  export async function GET(): Promise<Response> {
    if (running) return new Response('a run is already in progress', { status: 429 });
    running = true;
    const encoder = new TextEncoder();
    const stream = new ReadableStream({
      async start(controller) {
        try {
          for await (const event of runDemo(liveDeps())) {
            controller.enqueue(encoder.encode(`data: ${JSON.stringify(event)}\n\n`));
          }
          controller.enqueue(encoder.encode('event: end\ndata: {}\n\n'));
        } finally {
          running = false;
          controller.close();
        }
      },
    });
    return new Response(stream, { headers: { 'content-type': 'text/event-stream',
      'cache-control': 'no-cache', connection: 'keep-alive' } });
  }
  ```

  ```ts
  // web/lib/create/wallet.ts
  import { getNetwork, requestAccess, signTransaction } from '@stellar/freighter-api';
  import { Networks } from '@stellar/stellar-sdk';

  export async function connect(): Promise<{ address: string }> {
    const access = await requestAccess();
    if (access.error) throw new Error(access.error.message);
    const net = await getNetwork();
    if (net.error) throw new Error(net.error.message);
    if (net.networkPassphrase !== Networks.TESTNET) throw new Error('Freighter is not on testnet');
    return { address: access.address };
  }
  ```

  ```ts
  // web/lib/create/deploy.ts
  import { Keypair, Networks, contract } from '@stellar/stellar-sdk';
  import { generateAllowanceSalt } from '@stellar-allowance/sdk';
  import { freighterSigner } from './wallet.js';

  export interface Rules { name: string; token: string; deposit: bigint; cap: bigint; windowLedgers: number; allowlist: string[]; }

  export async function deployAllowance(owner: string, index: number, wasmHash: string, rules: Rules) {
    const agent = Keypair.random();
    const deployment = await contract.Client.deploy(
      { setup: { owner, agent_key: Buffer.from(agent.rawPublicKey()), name: rules.name,
        spending: { token: rules.token, initial_deposit: rules.deposit },
        rules: { window_ledgers: rules.windowLedgers, window_cap: rules.cap, allowlist: rules.allowlist } } },
      { wasmHash, salt: generateAllowanceSalt(owner, index), networkPassphrase: Networks.TESTNET,
        rpcUrl: 'https://soroban-testnet.stellar.org', publicKey: owner, signTransaction: freighterSigner });
    const { result } = await deployment.signAndSend();
    return { id: result.options.contractId as string, secret: agent.secret() };
  }
  ```
