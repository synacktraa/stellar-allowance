# Factory implementation plan

**Goal:** an immutable factory that deploys allowances at addresses derived from the owner, so
the interface and the SDK find them without a database.

**Architecture:** one Soroban contract holding a single value, the allowance wasm hash, set at
construction with no setter. `create` requires auth from `setup.owner`, derives
`sha256(owner ‖ index)` as the salt, and deploys with `with_current_contract`. Design:
`docs/specs/2026-09-06-factory-design.md`.

**Tech stack:** Rust, soroban-sdk 25, stellar-cli 27.1.0, wasm32v1-none.

Phase 1 changes the allowance and must land first, because the factory pins a wasm hash and
changing it afterwards costs a new factory and a new SDK release.

---

## Outcome

Phase 1 shipped as allowance 0.2.0 in
[#13](https://github.com/synacktraa/stellar-allowance/pull/13) on 2026-09-06.

Phase 2 was built through Task 12 and deleted before Task 13, on the same day.
[`../specs/2026-09-06-no-factory.md`](../specs/2026-09-06-no-factory.md) records what settled
it. The branch tip is tagged `factory-experiment`. Task 8's address derivation is the part
that survived, as `deriveAllowanceAddress` in the SDK.

  ```rust
  //! Deploys allowances at addresses derived from their owner.

  use soroban_sdk::{
      contract, contractimpl, contracttype, xdr::ToXdr, Address, Bytes, BytesN, Env, String, Vec,
  };

  #[contracttype]
  #[derive(Clone)]
  pub struct Spending {
      pub token: Address,
      pub initial_deposit: i128,
  }

  #[contracttype]
  #[derive(Clone)]
  pub struct Rules {
      pub window_ledgers: u32,
      pub window_cap: i128,
      pub allowlist: Vec<Address>,
  }

  #[contracttype]
  #[derive(Clone)]
  pub struct Setup {
      pub owner: Address,
      pub agent_key: BytesN<32>,
      pub name: String,
      pub spending: Spending,
      pub rules: Rules,
  }

  #[contracttype]
  pub enum DataKey {
      Wasm,
  }

  #[contract]
  pub struct Factory;

  #[contractimpl]
  impl Factory {
      pub fn __constructor(env: Env, allowance_wasm: BytesN<32>) {
          env.storage().instance().set(&DataKey::Wasm, &allowance_wasm);
      }
  }

  mod test;
  ```

  ```rust
  /// The owner is in the salt so that an address can only be occupied by whoever can

  fn salt_for(env: &Env, owner: &Address, index: u32) -> BytesN<32> {
      let mut buf = Bytes::new(env);
      buf.append(&owner.clone().to_xdr(env));
      buf.append(&index.to_xdr(env));
      env.crypto().sha256(&buf).into()
  }
  ```

  ```rust
  /// Deploys an allowance and runs its constructor in the same invocation, so the owner
  /// signs once for the contract, its rules and its opening deposit.
  ///
  /// The auth demanded here is on the address the salt was derived from. The allowance
  /// constructor demands its own, on the address it stores. They are the same address
  /// only while both declarations of `Setup` agree.
  pub fn create(env: Env, setup: Setup, index: u32) -> Address {
      setup.owner.require_auth();
      let salt = salt_for(&env, &setup.owner, index);
      let wasm: BytesN<32> = env.storage().instance().get(&DataKey::Wasm).unwrap();
      env.deployer()
          .with_current_contract(salt)

  }
  ```
